# NLP Pipeline Design

## Purpose

Convert speech transcript text into presentation intents and drive appropriate robot gestures.

---

## Intent Taxonomy

| Intent | Description | Default Gesture |
|--------|-------------|----------------|
| GREETING | Opening, hello, good morning/afternoon/evening | LOOK_AUDIENCE |
| INTRODUCTION | "I am...", "My name is..." | CENTER |
| QUESTION | Interrogative sentences | TILT_FORWARD |
| AGREEMENT | Yes, correct, absolutely | YES |
| DISAGREEMENT | No, incorrect, not quite | NO |
| EMPHASIS | "This is important", "Key point is..." | NOD |
| ACKNOWLEDGEMENT | "Thank you", "Good point" | CENTER |
| CONCLUSION | "In conclusion", "To summarize..." | CENTER |
| NEUTRAL | No strong intent detected | none |

All intents and their associated gestures are configurable. No intent is hard-coded to a gesture in application logic.

---

## NLP Service Architecture

```
Speech text input
  ↓
NLPService.analyze(text)
  ↓
Provider.classify(text)
  ├── RuleBasedProvider (default, no API key needed)
  ├── OpenAIProvider (optional, requires key)
  └── LocalLLMProvider (future)
  ↓
IntentResult {intent, confidence, suggested_gesture}
  ↓
Threshold check (skip if confidence < NLP_CONFIDENCE_THRESHOLD)
  ↓
Cooldown check (avoid repeated triggers)
  ↓
MovementDecisionEngine → gesture execution
```

## Rule-Based Provider (Phase 11 default)

No external API required. Pattern matching on keywords/phrases.

```python
INTENT_PATTERNS = {
    "GREETING": [
        r"\bgood morning\b", r"\bgood afternoon\b", r"\bgood evening\b",
        r"\bhello\b", r"\bhi everyone\b", r"\bwelcome\b"
    ],
    "AGREEMENT": [
        r"\byes\b", r"\bcorrect\b", r"\babsolutely\b", r"\bindeed\b",
        r"\bthat.s right\b", r"\bexactly\b"
    ],
    "DISAGREEMENT": [
        r"\bno\b", r"\bnot quite\b", r"\bincorrect\b", r"\bwrong\b",
        r"\bactually\b"
    ],
    "QUESTION": [
        r"\?$", r"^(what|why|how|when|where|who|which|do you|can you|would you)"
    ],
    "EMPHASIS": [
        r"\bimportant\b", r"\bcrucial\b", r"\bkey point\b",
        r"\bnote that\b", r"\bremember\b"
    ],
    "CONCLUSION": [
        r"\bin conclusion\b", r"\bto summarize\b", r"\bfinally\b",
        r"\bto wrap up\b", r"\bthank you for\b"
    ],
    "ACKNOWLEDGEMENT": [
        r"\bthank you\b", r"\bthanks\b", r"\bgreat question\b",
        r"\bgood point\b"
    ],
    "INTRODUCTION": [
        r"\bmy name is\b", r"\bi am\b", r"\btoday i.ll\b",
        r"\btoday we.ll\b"
    ]
}
```

## NLP Response Format

```json
{
  "text": "Do you agree with this approach?",
  "intent": "QUESTION",
  "confidence": 0.88,
  "suggested_gesture": null,
  "action_triggered": false,
  "cooldown_active": false,
  "provider": "rule_based"
}
```

When confidence >= threshold and cooldown not active:
```json
{
  "text": "Yes, absolutely correct.",
  "intent": "AGREEMENT",
  "confidence": 0.95,
  "suggested_gesture": "YES",
  "action_triggered": true,
  "cooldown_active": false,
  "provider": "rule_based"
}
```

## Context Awareness

The NLP engine should maintain a short context window.

A single word "yes" mid-sentence should not always trigger a YES gesture.
Context from surrounding words matters.

Phase 11 initial implementation: single-utterance analysis only.
Context window: future enhancement.

---

## Configurable Rules

Admins can add/modify intents via API without code changes:

```json
{
  "intent": "TECHNICAL_TERM",
  "patterns": ["machine learning", "neural network", "artificial intelligence"],
  "gesture": "EMPHASIS",
  "confidence_override": 0.9
}
```

Stored in DB or config file.

---

## Gesture → Intent Mapping

NOT every detected intent must trigger a gesture.

Default gesture assignment table (configurable in DB/config):

| Intent | Gesture | Condition |
|--------|---------|-----------|
| AGREEMENT | YES | Always |
| DISAGREEMENT | NO | Always |
| GREETING | LOOK_AUDIENCE | Session start only |
| QUESTION | TILT_FORWARD | If robot is "presenter" |
| EMPHASIS | NOD | 50% probability (avoid over-gesturing) |
| CONCLUSION | CENTER | Always |
| NEUTRAL | (none) | Never trigger |

## Time-Aware Greeting

```python
def get_time_aware_greeting() -> str:
    now = datetime.now()
    hour = now.hour

    if hour < settings.GREETING_MORNING_END:     # default 12
        return "Good morning"
    elif hour < settings.GREETING_AFTERNOON_END:  # default 17
        return "Good afternoon"
    else:
        return "Good evening"
```

Configurable via `.env`:
```
GREETING_MORNING_END=12
GREETING_AFTERNOON_END=17
```

Full greeting generated by presentation engine:
```python
greeting = f"{get_time_aware_greeting()} everyone. Welcome to today's presentation."
```
